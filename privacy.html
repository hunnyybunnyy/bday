Privacy & visits.

This birthday website records basic visit events when hosted on Netlify: opening a page, unlocking the birthday envelope, and opening the rose bouquet. These events are submitted to the website owner through Netlify Forms. The event includes the page name and action, but not your name or the code you entered. The hosting provider may also process technical information such as IP addresses to deliver the site. This website cannot confirm who is visiting or whether someone is currently online. The shared four-digit code is a fun entrance, not secure access control.
